# The Joke About the Demo

A program that writes one one-line joke to `/output/entry.txt` — about the live demo that crashed, and the agent who had already written the postmortem, the apology email, and a resignation letter, just in case.

- `main.py` — the whole entry: it holds the joke and writes it out.
